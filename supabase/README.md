# Supabase (ฐานข้อมูล)

ฐานข้อมูลจริงแก้ผ่าน Supabase SQL Editor — ไฟล์ในโฟลเดอร์นี้เป็นบันทึกว่ารันอะไรไปแล้ว และเครื่องมือตรวจ

| ไฟล์ | คืออะไร | เขียนข้อมูล? |
|---|---|---|
| `00_inspect.sql` | ดึงโครงสร้างทั้งหมด (ตาราง, RLS, สิทธิ์, trigger, ฟังก์ชัน, ค่าตั้ง, จำนวนแถว) เป็นข้อความเดียว ไม่มีข้อมูลส่วนบุคคล | ไม่ (อ่านอย่างเดียว) |
| `02_fix_race.sql` | unique `bookings.shop_id` + `book_stall` ต้องถือ hold + `cancel_booking` เข้าคิวแถว — **รันบน production แล้ว 15 พ.ย. 2569** | ใช่ |
| `race_test.js` | วางใน DevTools Console ของเว็บ (ล็อกอินบัญชีที่ยังไม่จอง) ยิง hold/จองพร้อมกันเพื่อหา race แล้วล้างข้อมูลให้เอง | ใช่ (บัญชีทดสอบเท่านั้น) |

SQL ที่รันก่อนหน้านี้ (ตาราง, RLS, `hold_stall`, `stall_snapshot` ฯลฯ) ไม่ได้เก็บเป็นไฟล์ — ดูสภาพปัจจุบันจาก `00_inspect.sql`
ครั้งต่อไปที่แก้ฐานข้อมูล ให้เพิ่มไฟล์ `NN_<เรื่อง>.sql` ที่นี่ด้วย (ห่อด้วย `begin; … commit;`)
